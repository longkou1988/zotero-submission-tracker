# 测试与验收

## 自动化检查

在项目目录执行：

```sh
npm install
npm run check
```

`check` 依次执行 TypeScript 类型检查、Vitest 自动化测试和 XPI 构建。测试覆盖状态计算、时间线、跟进日期、重复投稿、系统配置归档、JSON 校验、CSV 转义、安全边界、原子写入失败与 `.bak` 回退。

## 干净 Zotero 配置验收

不要使用唯一的日常 Zotero 配置进行首次测试。为每个目标版本创建独立测试配置，并执行：

1. 从“工具 → 附加组件”安装 XPI。
2. 确认“工具 → 投稿追踪”可打开看板。
3. 普通文献右键出现“创建投稿记录”；附件、笔记、批注不出现。
4. 创建投稿，添加第二次投稿，更新状态，并补录一条更早的状态。
5. 设置昨天、今天、第 7 天和第 8 天日期，核对提醒分类。
6. 打开投稿系统，确认系统默认浏览器收到正确 URL；复制用户名后核对剪贴板。
7. 删除关联 Zotero 条目，确认投稿仍存在；重新关联另一文献。
8. 导出 JSON 和 CSV；确认 CSV 不含用户名。
9. 清空数据后恢复 JSON；确认记录与时间线一致。
10. 重启 Zotero并重新启用插件，确认数据仍在。

| Windows | 待测 | 待测 | 待测 | 未完成 |
| Linux | 待测 | 待测 | 待测 | 未完成 |

最低公开发布门槛是三个平台上的目标 Zotero 版本均完成“安装 → 创建投稿 → 更新状态 → 设置逾期 → 打开系统 → 导出 JSON → 重启 → 验证数据”。Zotero 10 若仍为 Beta，应清楚标注 Beta 验证，不能写成稳定版验证。
